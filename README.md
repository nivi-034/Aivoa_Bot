# 🚀 AIVOA – AI-Powered Customer Complaint Management System

AIVOA is an intelligent complaint management platform that automates the processing of customer complaints using Large Language Models (LLMs). The system transforms unstructured complaint documents into structured records, enabling faster decision-making, improved efficiency, and streamlined complaint management.

Whether the complaint is uploaded as a PDF, TXT file, or entered manually, AIVOA extracts key information, categorizes the complaint, assesses its priority, and stores it for future tracking and analysis.

---

## ✨ Key Features

- 📄 Upload complaint documents in PDF and TXT formats
- 📝 Submit complaints through manual text input
- 🤖 AI-powered extraction of complaint details using Groq LLM
- 📋 Automatic identification of:
  - Customer Name
  - Product Name
  - Product Strength / Grade
  - Batch / Lot Number
  - Quantity Affected
  - Manufacture Date
  - Expiry Date
  - Complaint Type
  - Complaint Description
  - Initial Severity
  - Priority
  - Complaint Source
- 💾 Store complaints securely in PostgreSQL
- 📊 Interactive dashboard with complaint statistics and history
- 💬 AI Assistant for complaint summarization and question answering
- ⚡ Fast, accurate, and scalable complaint processing

---

## 💡 Problem Statement

Organizations often receive complaints in lengthy documents, emails, or reports that require significant manual effort to review and process. This process is time-consuming, prone to human error, and delays decision-making.

AIVOA addresses this challenge by automatically extracting critical complaint information using Generative AI, significantly reducing manual effort while improving consistency and operational efficiency.
